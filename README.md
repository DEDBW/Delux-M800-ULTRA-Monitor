# 🖱️ Delux M800 Ultra — Battery Monitor & Notifier

[![GitHub release](https://img.shields.io/github/v/release/trend/Delux-M800-Ultra-Battery-Monitor?label=Release&color=brightgreen)](https://github.com/)
![Platform](https://img.shields.io/badge/Platform-Windows%2010%20%7C%2011-blue)
![Python](https://img.shields.io/badge/Python-3.11+-yellow)
![License](https://img.shields.io/badge/License-MIT-lightgrey)

Легковесная утилита для Windows, которая в реальном времени отслеживает уровень заряда аккумулятора беспроводной мыши **Delux M800 Ultra** и присылает системные всплывающие уведомления при разряде.

Работает напрямую через USB/HID протокол — **тяжелый официальный софт Delux держать запущенным не требуется**.

---

## ✨ Возможности

- 🔋 **Прямой опрос мыши (HID)**: опрос беспроводного донгла 2.4G или кабеля без сторонних драйверов.
- 🔔 **Всплывающие уведомления Windows (Toast)**:
  - ⚠️ Предупреждение о низком заряде (настраиваемый порог, по умолчанию **20%**).
  - 🚨 Предупреждение о критическом заряде (по умолчанию **10%**).
  - ⚡ Оповещение о 100% полном заряде аккумулятора.
  - 🛡️ Защита от спама (cooldown): уведомления не повторяются каждую минуту.
- 🎯 **Динамическая иконка в трее (System Tray)**:
  - Отображает уровень заряда и точный процент прямо на миниатюре батарейки.
  - Цветовая индикация: 🟢 Зеленый (>40%) / 🟡 Желтый (21–40%) / 🔴 Красный (≤20%) / ⚡ Бирюзовый (зарядка).
  - Контекстное меню с быстрым доступом к настройкам и автозапуску.
- 🌙 **Современный интерфейс в тёмной теме (CustomTkinter)**:
  - Визуализация мыши и заряда в реальном времени.
  - Настройка порогов срабатывания ползунками (1%–100%).
  - Выбор частоты проверки (от 30 сек до 10 мин, практически 0% нагрузки на процессор).
  - Звуковые оповещения и автозапуск вместе с Windows.

## 📥 Установка и запуск

### Вариант 1: Готовый `.exe` (Рекомендуется)
1. Перейдите на вкладку **[Releases](../../releases)** репозитория.
2. Скачайте последнюю версию `DeluxBatteryMonitor.exe`.
3. Запустите файл — программа начнет работу и появится в системном трее Windows (возле часов).

---

### Вариант 2: Запуск из исходного кода Python

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/<ваш-аккаунт>/<репозиторий>.git
   cd "Delux M800 ULTRA"
   ```

2. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустите приложение**:
   ```bash
   python main.py
   ```
   *(Для запуска без фонового окна консоли используйте `pythonw main.py`)*

---

## ⚙️ Настройки и автозапуск

- **Конфигурация**: настройки сохраняются в `%LOCALAPPDATA%\DeluxBatteryMonitor\config.json`.
- **Автозапуск с Windows**: включается в окне настроек или через меню в трее (создает безопасный ярлык в папке автозагрузки пользователя).
- **Сворачивание в трей**: при закрытии окна крестиком программа продолжает работать в фоне.
- **Выход**: кликните правой кнопкой мыши по иконке в трее и нажмите **«Выход»**.
